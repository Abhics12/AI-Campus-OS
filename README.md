# AI Campus OS — Final Isolated Workspace Build

Developer: Abhijeet Kumar Singh

This build is designed around the requested model: one app, but each Department + Year behaves like a separate app/workspace.

Features included in the UI/data model include Admin, Teacher and Student roles, sections A–E, subject/teacher management, attendance, labs/batches, assignments/physical submission/marks, timetable files, notifications, and workspace/Drive management.

See `DEPLOYMENT.md` for the only account-specific configuration required for a real production deployment.
